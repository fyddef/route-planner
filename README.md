# 🗺️ Умный планировщик маршрутов и рельефа

Интерактивное веб-приложение для планирования прогулок, пробежек и поездок с визуализацией карты, профиля высот и интерактивным графиком рельефа. Работает полностью в браузере (на чистом JavaScript, Leaflet.js и Chart.js).

## ✨ Возможности
* Интерактивная карта с возможностью ставить точки маршрута кликом.
* Автоматический расчет общей дистанции и набор высоты.
* Интерактивный график высот: наведите курсор на график, чтобы увидеть точную точку на карте.
* Экспорт готового маршрута в формате `.gpx` для навигаторов и смарт-часов.
* Работает без серверов и бэкенда (100% клиентская часть).

## 🚀 Как запустить локально
Просто скачайте файл `index.html` и откройте его в любом современном браузере!
